# UI Design Starter

Use this layout to kickstart most mobile apps:

- Top Header
  - App title
  - Small subtitle or context

- Tab Navigation (4 tabs)
  - Home
  - Explore
  - Activity
  - Profile

- Home Screen
  - 2-3 key metric cards
  - Quick actions block
  - Main list preview

- Explore Screen
  - Search bar
  - Categories chips
  - Scrollable card list

- Activity Screen
  - Timeline items
  - Date grouping
  - Filters by type

- Profile Screen
  - User info card
  - Preferences/settings cards
  - Logout/action button

# Recommended Build Order

1. Define app data types
2. Build Home metrics + cards
3. Build one real feature tab
4. Connect local storage
5. Add polish (empty states/loading)
